# Arcade library screenshots

Real Choano gameplay, captured from the existing `tests/visual_scene.zi`
shark encounter fixture on a private Xvfb display. The fixture renders the
normal game view with a deterministic run and the game’s own artwork.
Only its owned test window was captured. The landscape and portrait sources
are separate window layouts. No title artwork or invented artwork is used.
Arcade generates bounded WebP copies in its separate library art pipeline;
these source screenshots are outside Choano’s embedded game asset folders.
